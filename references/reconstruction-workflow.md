# 扫描图建模与空间核查操作要点

## 资料、比例和定位

- 识读页面前先按楼层、图种列页并检查缺页；把轴号、可辨的尺寸链、标高、图例、房间名、门窗编号及截图问题建立对应关系。源图局部、已确认量与候选量各自留出处。
- 对每页选分布较广的尺寸/轴交控制点，分别核对水平与竖向；若发生透视、拉伸或扫描倾斜，分区配准并记录偏差。无法足够校准时说明范围，不提高标注精度冒充实测。
- 以真实单位和共同原点建立工作坐标；多楼层比较前用同一组对应轴线对齐，并记录变换；轴号不一致或图纸版本不同时先核实。

## 以构件和空间关系画图

- 先画轴网和能从资料识别的外围、结构与主要围护，再逐房间绘制隔墙及其与外墙、柱、井道的连接，之后开门窗并布置楼梯、电梯和卫具。房间边界是否合理，应结合墙体、门洞、玻璃、开敞边和空间功能判断，而不是用所有线段强制闭合。
- 若以双线画墙，先由墙中心线、基准边及对应厚度确定两侧面，再处理相交、转角和洞口；两侧随墙厚一起连接。相邻墙厚不同的接头根据原图明确过渡，拒绝无依据的细小台阶或突出。对斜角取真实交点；不同构件相交要按原图分清连续墙和接入墙。
- 所有门窗需有与两侧墙端匹配的洞口、门扇/窗框；检查门铰、开启朝向、门洞与周围可用空间，特别是楼梯间、机房和走道。原图有局部不清时记录假设；设计意图与既有现场不一定一致。
- 楼梯核查边界、梯段、踏步、平台、上下方向及与入口/走廊的关系；电梯核查井道、厅门及候梯空间；卫具核查位置和进入路径。无法依据图纸判断的实际净空、坡度、梯级尺寸或通行条件，标现场核实。
- 同轴跨层比较时，把柱的位置、候选截面、识别来源与该层材料分别登记；不因柱子在图面局部被墙遮挡就判缺失，不把同轴候选当作已核定结构。

## 输出、对照和追踪

- 优先使用现场可用的 CAD 软件、经过验证的可编辑构件库或脚本进行建模。仅有脚本环境时，可使用 `ezdxf` 生成按功能分层的线、弧、块、文字和标注，再通过可用 CAD 程序转成 DWG。不得虚报未验证的转换或专用构件支持。
- 构件层应至少区分轴网、墙、柱、门、窗、楼梯/电梯、设备、标注、待核项；图层具体名称依用户标准或项目约定，不用按颜色推断构件语义。
- 校核每一处截图箭头，保留源页或参考视图、修改后同尺度局部、对象与修改依据。列表状态只写“已修正并复核 / 候选待核 / 未检查 / 原图确为转折”等真实情况，不能只凭代码候选数宣布完成。
- 现场核对清单至少包括定位楼层与轴线、问题对象、图面原值、模型候选值、是否有遮挡或缺页、现场需要测量的对象和具体记录位置；留空现场实测值供填写。
