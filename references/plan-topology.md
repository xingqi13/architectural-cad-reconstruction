# 建筑平面推理与验收

## 先读成一层建筑

- 根据轴号、跨距、定位尺寸和不同区域的控制点建立同一坐标网。跨层复用已核对的轴号与基准，再识别柱截面变化、偏心和实际错层。扫描局部变形先与总尺寸和相邻跨核对。
- 建立空间表，至少记录 `楼层、名称、所处轴跨、边界分类、共用墙、洞口、证据、待核项`。沿外围走一圈，再按楼梯、电梯、走廊等固定空间向相邻房间展开。外墙、玻璃围护、共用隔墙、临空栏杆、开敞边界、活动隔断和疑似缺线分别辨认。图号、轴线、门扇、填充或设备符号提供识读线索，围护由实际墙、柱、封闭玻璃等构成。
- 两房共用墙引用同一墙位。逐井查电梯井四周、相邻井分隔、净尺寸、侧墙与后墙、入口两侧门垛及门洞。电梯门、电梯简图和井内叉线各有制图用途，井道围护另建完整。楼梯间同样逐边查围护，并核楼梯的方向、平台、净宽和出入口衔接。

## 按图线与空间功能判定构件

- 先读原图图例、完整平面、门窗表及对应剖面。按图线用途区分剖到的实体、可见轮廓和投影、设备及开启符号、地坪或其他边界、定位轴线。扫描后的深浅与像素线宽用于定位线索。原图图例、构件编号和相关图纸用于定性，标注尺寸和定位关系用于定量。[ISO 7519:2025](https://www.iso.org/standard/89718.html) · [ISO 128-2:2022](https://www.iso.org/standard/83355.html) · [ISO 128-3:2022](https://www.iso.org/standard/83356.html)
- 画短墙、返边或封口前，先说清它分隔哪两个空间，或服务于哪个门垛、井道、设备龛或结构节点。原图细线、门扇扫弧、投影线和相邻墙的旧端帽需辨认来源。对疑似缺口，分别检查有据的开口、不同线型在同一节点的交接及实体确实脱开。无法确认构造时，保留有依据的空间关系并注明具体待核项。
- 沿围护走到每个门窗端部，记录端点接哪道墙、哪一柱面或哪段相邻围护。用门窗表确认玻璃、百叶、设备口等类型。墙内有有效洞口后，还要用墙面、柱面和两端连接判断空间是否表达正确。填充用于检验已识别的围护连通，之后按门窗表和相邻空间复查构件类型、通行和收口。

## 扫描纠偏与叠图复核

1. **建立独立控制。** 先确认扫描页、楼层、比例、单位和方向。优先选择图载轴网交点、已知定位尺寸和结构图能互证的点，分布在四周和中部。区分作为控制的轴线、已确认的墙面和有依据的真实斜墙、退进或错台。记录扫描像素坐标、CAD 坐标和来源，把部分控制点留作独立验证。待检查的构件及与它存在同一争议的线位均不作配准点。
2. **先全图后局部。** 先比较横纵长轴的方向与比例。用覆盖全页的非共线控制点拟合全图仿射，检查旋转、横纵尺度、剪切和残差的空间分布。保留原扫描，校正只作用于对照图。比较校正前后的留出点误差，记录残差方向、均方根和最大值；有可信比例时换算成毫米。留出点仍显示局部漂移时，用同一梯井的已确认围护、轴线、控制墙面或柱边局部微调，并用邻近独立基准再验一次。局部证据不足时保留疑点，控制范围外的外推不用于定量核查。
3. **叠合实际回读图。** 打开用于交付的同版 DWG，用天正或对应原生环境出图，核对墙柱、洞口和其他构件在重开后的显示。把原扫描或其校正版与实际回读图置于同一坐标画布，用颜色和图层开关对比，分别看整体和局部。HTML 叠图可借鉴 [image-to-cad 的交互对照页](https://github.com/leoyang1984/image-to-cad-skill/blob/2e86b7fbf4b755228d41bc6fcabc35b607da3bf1/skills/image-to-cad/scripts/review_page.py)。
4. **先判关系，再量差值。** 对照长墙控制面和墙柱接头，查围护闭合、真实开口、相邻空间与流线。楼梯按梯井两边和平台辨认上下行、折断线落在哪一跑及踏步、门槛的关系。几何差值要结合局部留出点残差、线宽、清晰度与图载尺寸解释；门开错方向、折断线位于另一跑等语义差异可独立确认。叠图偏差不能直接作为工程尺寸或据此移动构件，有疑问时查原标注、平立剖或标注待现场核实。

## 将长墙作为整体控制

1. 为每条连续墙明确 `控制线、统一方向、左右偏移、墙厚、起讫/跨数、真实变更位置、节点、洞口、依据`。先在工作底稿沿同一基准和有依据的同类墙厚拉通整段，再逐点核查门窗洞口、柱面收口以及真实的转折和变厚，最后分配到 CAD 对象。墙位连续可确认而厚度缺证据时，先锁定边界走向并登记待核厚度。
2. **同轴先判断控制方式。** 常见方式包括墙中心对轴线、同侧墙面对齐、墙面按明确距离偏离轴线。除依据明确的变化外，同一连续墙在洞口、柱垛、T 接和建模分段前后延续同一控制方式。在同轴线上发现孤立错台，先排查比例变形、读图误差和建模偏移，再用源尺寸或相邻详图判断。真实退进、斜接、弧墙、层间偏移及材料厚度变化按源图登记。
3. **厚度与墙面一起核。** 同一构造的两条墙边沿程保持匹配。有依据的变厚若需要保持内墙面或外墙面共线，就调整另一侧的偏移。墙方向翻转时复算左右偏移。不同构造或不同厚度的相邻墙按真实节点关系相交，转角处理两条墙边。
4. **柱以轴线与截面为依据。** 先查每根柱的定位点、中心、截面、旋转和两向偏心。图源支持对中的柱按轴交点对中。已经确认的边柱、角柱偏心或柱面凸出按原图保留。墙按源图要求齐柱内边、外边或另一指定控制面，重算墙的左右偏移，保持柱的结构定位。沿同一轴线与不同楼层复查漏柱、误柱、尺寸、柱心及墙内柱，不能识别时登记待核范围。
5. 每樘洞口绑定相应墙位并登记端点、类型、宽度、两侧门垛、连接空间和开启方向，窗台/门槛与高度按图源分级。门窗和柱附近的断线先分类，补墙前核对源图洞口。遇到开放通道、挑空、伸缩缝等，保留真实范围。

## 逐圈与逐间验收

- **先定空间功能。** 结合房名及用途标注、原图门洞与开启方向、跨层用途，辨认可进入的房间、有门控制的楼梯间或前室、围护封闭且仅供检修的竖井，以及原有开放空间。逐间确定预期围护、入口和连通对象。开敞边界按源图用途与流线检查。
- **用房间填充复核。** 在独立验收副本或内存边界中，用实际墙、柱、封闭玻璃的围护面检查连通区。仅在该验收几何中对已确认的原生洞口临时封边。在各房间取种子点，并在门口及疑似断口两侧分别取种子点，根据两侧种子点的连通结果判断是同一空间、预定开敞、正常分隔，还是误串到邻室或室外。再以真实门洞核对通达关系。HATCH 无法闭合时，先查选层、端缝和临时封口，再用原图判定是否真缺墙。临时封边及验收填充仅用于复核，交付 DWG 保留实际围护与洞口。
- **夹墙内的小井。** 对楼梯侧边的 SS、PS 等竖井或狭长空间，在纠偏原扫上分别追踪两侧实墙、端部返墙、相邻柱面和检修开口，用独立种子点核查空腔及其与楼梯间的分隔。原稿用实墙填满已辨认的空腔时，按有依据的边界恢复围护。墙厚、净宽或柱面收口缺证据时，按部位标注待现场核实。
- **直墙通线。** 量起端、中部、末端，另查洞口两侧、墙柱两侧和墙转折处，复测相对共用控制面的垂距、两侧墙面和墙厚，并按源图指定的柱内面或外面核对墙体两端的实体接合。确认 T、L、十字和斜接没有误缝、重叠闭口线、突刺、穿出或短墙漂移。根据图纸比例、控制点残差、输出精度与节点证据确定复核容差。超差或缺证据的节点定位标注待核。
- **洞口与流线。** 查门窗和宿主是否匹配、墙内是否真有洞、方向和门垛是否符合原图。验证门连到预期房间、走廊、楼梯或室外，窗和设备洞按各自用途核对。另查通行性、门槛和踏步衔接。
- **报告复核范围。** 图内待核可用 `楼层/轴跨/侧别 + 具体尺寸或冲突`。核查过的范围、受源图限制的范围、已实测值与模型假定分别写清。墙中线 polygonize、天正搜索房间或对象数量可辅助筛查，完整性以实际构件、真实洞口、房间围护和重开图显示判定。


### 核心筒内的小井与相邻墙角

遇到 PS、FA 等井名及长×宽标注，沿原扫描辨认井内留白、四周井壁和相邻实体的共用边界。成对线识别容易跨过整个井，把净空建成一块厚墙。取井内点检查是否落入墙体，并在两个方向核对净尺寸。图载值与图面量取值分别记录。电梯井角邻接小井时，选中两道原生墙查看基线端点，再对相交处执行天正「修墙角」。取消选择并保存重开，逐条追查电梯井内角、外围通线及小井边界，确认墙体内无残留端线，并保留真实门垛和构造分界。
